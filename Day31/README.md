# 🚗 Smart Vehicle Counting System

An AI-based vehicle detection, tracking, and counting system using YOLOv8, OpenCV, and ByteTrack.

## Features

- Upload traffic videos
- Detect vehicles using YOLOv8
- Track vehicles using ByteTrack
- Assign unique tracking IDs
- Count vehicles crossing a line
- Detect:
  - Cars
  - Motorcycles
  - Buses
  - Trucks
- Display vehicle statistics
- Save processed output video

## Technologies Used

- Python
- YOLOv8
- Ultralytics
- OpenCV
- ByteTrack
- Streamlit
